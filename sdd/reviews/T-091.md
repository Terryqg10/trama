## Problemas conocidos

- **`checkout.spec.ts:180` falla, y no por este cambio.** «si el stock bajó por debajo de la cantidad…» espera «solo quedan 8» y el servidor responde «solo quedan **6**»: la semilla deja 8 unidades de cada variante, y la compra de prueba hecha en la web desplegada (que comparte la base de datos con desarrollo) descontó 2 del polo negro talla M. **Se arregla restaurando el stock a 8**, no tocando el test ni el código; ver más abajo. Hasta entonces ese test seguirá fallando en `chromium` y `mobile`.
- La compra de prueba también dejó un pedido pagado, una dirección y un usuario de prueba en la base de datos compartida. Conviene limpiarlos antes de enseñar la demo.
- El proyecto de Supabase es el mismo para desarrollo y para la web desplegada: los datos de una compra de demostración afectan a los tests (ya anotado como riesgo en la Enmienda 41).
