## Problemas conocidos

- **Descubrimiento:** el cortafuegos de Supabase (Cloudflare) bloqueaba con una página HTML un texto como `'; drop table products; --` y la API respondía 500. `parseSearchQuery` pasa ahora a **lista blanca** (letras, números y guiones): comillas, `;`, `%`, `_`, `*`, `=` y paréntesis pasan a espacio. Nada de eso aparece en un nombre de producto y se evita que la IP del servidor sea bloqueada.
- El mensaje de error de `searchProducts` se recorta a 200 caracteres (antes volcaba la página HTML entera al registro).
- **CA-93 sigue vigente:** `/buscar?q=<b>x</b>` ahora muestra «b x b» (limpieza por lista blanca); el test comprueba que no se pinta como HTML.
- Sin límite por IP (VERIFICAR); lo acotan los 300 ms, el mínimo de 2 caracteres, el tope de 5, la caché de borde y la RLS.
