## Problemas conocidos

1. **El workflow no se ha ejecutado en GitHub Actions.** No hay repo git ni remoto. Hasta entonces nada garantiza que `ci.yml` pase en la nube (p. ej. paso `pnpm exec playwright install`, `test:e2e` contra `pnpm run start`, `gitleaks-action`).
2. **No es bloqueante de facto** hasta que el usuario haga `git init`, cree el remoto y active *branch protection* con los checks `main` y `gitleaks` como requeridos.
3. `pnpm test:e2e` no se ejecutó en local en esta tarea. Lo ejecuta CI.
4. La excepción de ADR-001 caduca el **2026-11-11**: desde esa fecha `audit:gate` falla hasta que haya parche o un ADR nuevo.
5. `scripts/audit-gate.mjs` no tiene test automático; la prueba negativa se hizo a mano con una copia y quedó documentada arriba.
6. Pendientes heredados de T-001: avisos de peer-deps de esbuild y `.env.example` sin revisar (permisos).
