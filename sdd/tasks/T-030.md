# T-030 — Círculos de color en la ficha

## Contexto

Petición del usuario al revisar la ficha: el selector de color usa chips de texto («Burdeos»,
«Negro») y debería mostrar un círculo con el color real, con el nombre del color elegido como
subtexto. Decisiones del usuario: el subtexto está **siempre visible** (muestra el color elegido,
también el preseleccionado al entrar) y los colores salen de **tokens CSS del proyecto** (ADR-007).
Los criterios están en la Enmienda 12 de SPEC-001 (CA-57 y CA-58).

## Cambio previsto

Sustituir los chips de texto de color por círculos con el color real. El color elegido lleva un
anillo, y el subtexto «Color: <nombre>» sigue sobre el selector. Los valores viven en
`src/app/swatches.css` (`--color-swatch-<color>`) y el mapa nombre→clase en
`src/lib/catalog/swatches.ts`. Un color sin token se muestra como chip de texto.

## Fuera de alcance de esta tarea

- Las tallas (siguen como chips de texto) y el resto de la ficha.
- Guardar el color en la BD o editarlo desde el panel admin (alternativa 3 de ADR-007).
- Cambiar los colores de las imágenes de ejemplo.
- Un tooltip propio (se usa `title`).

## Notas

- **Estilo:** `v1-soft-commerce@0.3.0` (elegido por el usuario). El color de la muestra nunca se
  escribe en un componente: solo clases con nombre de token (`bg-swatch-burdeos`).
- **No depender solo del color:** cada círculo es un enlace con el nombre del color como texto solo
  para lectores de pantalla; el elegido lleva `aria-current`, un anillo y el subtexto.
- **Objetivo táctil:** el enlace mide al menos 44×44 px aunque el círculo sea más pequeño.
- **Contraste:** el blanco y el beige sobre fondo claro se pierden sin borde: el círculo lleva borde
  (`border-border-strong`). Comprobar con axe y a ojo.
- Valores de los tokens: los mismos que `scripts/generate-placeholders.mjs`, para que muestra y foto
  coincidan.
- Los tests existentes de color buscan el enlace por nombre accesible («Negro»), que se conserva.

## Criterios de aceptación

| ID | Dado | Cuando | Entonces |
|---|---|---|---|
| CA-57 | Un producto con varios colores | Se abre la ficha | Cada color se muestra como un círculo de su color real, con el nombre como nombre accesible; el color elegido lleva un anillo y un subtexto con su nombre; pulsar otro círculo cambia el color elegido, la imagen y el subtexto |
| CA-58 | Un color del producto sin token de muestra | Se abre la ficha | Ese color se muestra como chip de texto, no como un círculo de otro color |
