# T-063 — API de búsqueda GET /api/search

## Contexto

Enmienda 27. Las sugerencias del buscador necesitan una ruta JSON.

## Cambio previsto

`src/app/api/search/route.ts` (GET): normaliza `q` con `parseSearchQuery`, devuelve `[]` si tiene menos de 2 caracteres y, si no, hasta 5 productos con `{ id, slug, name, priceCents, image }`.
